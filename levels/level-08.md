# Bandit Level 7 → 8

## Commands Used

```bash
ls
cat data.txt
cat data.txt | grep "millionth"
```

## What I Learned

- `cat` displays the contents of a file.
- `|` pipes the output of one command into another.
- `grep` filters text based on a specified pattern.
- Combining `cat` and `grep` allows me to search through a file without manually inspecting all its contents.
